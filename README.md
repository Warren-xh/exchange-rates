# 人民币汇率台

以人民币为基准的汇率换算网页。免费部署在 GitHub Pages，汇率每分钟自动刷新；货币清单、自定义汇率和目标价可以在任何设备上输入密码后修改并发布。和[行迹 Atlas](https://github.com/Warren-xh/travel-atlas)、[科研日志](https://github.com/Warren-xh/research-log)是同一套更新方式。

- [打开汇率台](https://warren-xh.github.io/exchange-rates/)

## 可以做什么

- 每种货币一眼看到「1 欧元 = 7.5185 元」，下面列出常用整数金额（欧元、泰铢、摩洛哥迪拉姆：10 / 100 / 1,000；日元：100 起；越南盾、印尼盾：1 万起），也可以在每一行输入任意金额换算成人民币。
- 现在列出：欧元、泰铢、越南盾、印尼盾、摩洛哥迪拉姆、日元。
- 鼠标放到货币上（手机上点「××物价」）显示当地物价：Numbeo 生活成本、超市、餐厅、房租指数与中国对比，以及 18 种常见商品和服务的当地价格、按实时汇率折合的人民币，和中国价格的倍数。欧元以爱尔兰为例。
- 汇率每分钟从 Coinbase 公开汇率刷新，连不上时改用 ExchangeRate-API；切回页面时立即刷新。
- 每种货币显示相对上一个欧洲央行参考价的涨跌（红涨绿跌，国内习惯）和近 30 天走势，数据来自 Frankfurter。
- 可以添加任意货币、自定义汇率（银行或汇款平台报价、实时汇率加点）和目标价。
- 明暗主题、手机适配。

物价数据保存在 `src/prices.js`，2026 年 10 月抓取；要更新就改里面的数字和日期，再运行 `node build.mjs`。

## 修改与发布

1. 点右上角「管理」，输入管理密码。
2. 修改标题、货币、自定义汇率、目标价或备注。草稿自动保存在当前设备，可以撤销、重做。
3. 点「发布修改」，查看修改清单，再点「确认发布到网站」。
4. 发布会在仓库里提交 `data/config.json`，其他设备打开页面就能看到；误改可以从提交历史找回。

多台设备同时修改时，发布前会自动合并不同的修改；改到同一项时由你选择保留哪一边。闲置 15 分钟自动锁定，草稿保留。

## 密码是怎么工作的

网站本身是静态页面，修改内容需要 GitHub 写入权限。第一次点「管理」时：

1. 在 GitHub 生成一个**只授权本仓库**的细粒度令牌（Contents 读写权限，最长一年）。
2. 粘贴令牌并设一个管理密码。

令牌在浏览器里用密码加密（PBKDF2 60 万次 + AES-256-GCM），只把加密结果保存为 `data/vault.json`。之后任何设备输入密码，就在本地解开令牌并直接提交。

- 密码不会被发送或保存到任何地方。
- 加密文件在公开仓库里，所以密码不要太简单，也不要和其他账号共用。
- 令牌只能改这一个仓库；万一泄露，到 GitHub 删除令牌，再在网站「网站设置 → 修改密码 / 更换令牌」里换一个。
- 令牌过期后同样在那里更换。

## 文件

| 路径 | 内容 |
| --- | --- |
| `index.html` | 网站本身（由 `build.mjs` 从 `src/` 生成） |
| `data/config.json` | 货币清单、自定义汇率、目标价和网站文字 |
| `data/vault.json` | 加密后的编辑授权（第一次设置后出现） |
| `src/core.js` | 汇率计算、格式化、修改清单和三方合并 |
| `src/prices.js` | 各国物价参考数据（Numbeo） |
| `src/github.js` | 密码保管库和 GitHub 读写 |
| `src/app.js` / `src/body.html` / `src/style.css` | 界面 |
| `tests/` | 自动测试 |

## 开发

需要 Node.js 18 以上，无运行时依赖：

```sh
node build.mjs        # 重新生成 index.html
npm test              # 单元测试
```

同一份代码也能作为 claude.ai 里的网页运行（`dist/fxdesk.html`），那时汇率由定时任务写入。

汇率仅供参考，实际兑换以银行或平台报价为准。
